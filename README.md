# Kestrel

Мониторинг Telegram-каналов через `tg_monitor.py`: скачивание постов в
локальную базу и (опционально) их рерайт через Claude.

## Установка

```
pip install telethon anthropic --break-system-packages
```

## Настройка

1. Зайдите на https://my.telegram.org, создайте приложение и получите
   `API_ID` и `API_HASH`.
2. Скопируйте `.env.example` в `.env` и заполните реальными значениями:
   `TG_API_ID`, `TG_API_HASH`, а для команды `rewrite` — ещё и
   `ANTHROPIC_API_KEY`. Файл `.env` в `.gitignore` и никогда не попадает
   в репозиторий.
3. Добавьте в `channels.txt` ссылки/юзернеймы каналов для мониторинга
   (по одному на строку).

## Использование

```
python tg_monitor.py fetch            # скачать новые посты из channels.txt
python tg_monitor.py list             # список сохранённых постов
python tg_monitor.py show <id>        # показать пост целиком
python tg_monitor.py rewrite <id>     # переписать пост через Claude
```

При первом запуске `fetch` Telethon попросит войти в Telegram (номер
телефона + код из СМС) — это нужно сделать один раз. После входа создаётся
файл сессии `tg_monitor_session*`.

## Безопасность

Репозиторий публичный, поэтому:

- В git попадает **только** `tg_monitor.py` (и `.env.example` с пустыми
  полями). Файлы `tg_monitor_session*`, `posts.db` и `.env` — в
  `.gitignore` и никогда не коммитятся.
- Файл сессии `tg_monitor_session*` — это ключ доступа к личному
  Telegram-аккаунту. Храните его только локально, никогда не публикуйте
  и не копируйте в общие хранилища.
- `posts.db` (скачанные посты) — тоже только локально.
- Перед каждым коммитом проверяйте `git status`, чтобы убедиться, что
  `tg_monitor_session*`, `posts.db` и `.env` не попали в staged-файлы.
- Если что-то из перечисленного всё же было закоммичено раньше — удаления
  файла следующим коммитом недостаточно, он останется в истории git.
  В этом случае нужно полностью почистить историю (`git filter-repo` или
  BFG Repo-Cleaner), затем считать скомпрометированными и пересоздать:
  файл сессии (войти в Telegram заново) и, если утёк, `ANTHROPIC_API_KEY`
  (перевыпустить ключ в кабинете Anthropic, старый отозвать).
- Данные из постов, файла сессии и `posts.db` используются только для
  личных нужд владельца и не передаются третьим лицам и не используются
  для обучения каких-либо моделей.
